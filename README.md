# Veille Sécurité — CDA (RNCP 37873)

Ressources pour mettre en place une **veille sur la sécurité des applications**, à destination des apprenants préparant le titre professionnel **Concepteur Développeur d'Applications**.

Module : *Actualiser et partager ses compétences en conception et développement d'applications* — partie « Assurer une veille technologique », atelier « Veille sur des tendances technologiques » et atelier « Partage de connaissances ».

## 📂 Travail demandé — Votre veille

Consignes et livrables : [`veille-securite/README.md`](veille-securite/README.md)

```
veille-securite/
├── README.md                      ← consignes, livrables, auto-évaluation
├── 01-plan-de-veille.md           ← périmètre, objectifs, routine
├── 02-journal-de-veille.md        ← une ligne par information triée
├── fiches/                        ← modèle + 5 fiches d'exemple
├── 03-synthese-mensuelle.md       ← synthèse diffusable (1 page)
├── 04-synthese-dossier-projet.md  ← partie « veille sécurité » du dossier de projet
└── 05-atelier-partage.md          ← support de l'atelier de partage
Abonnements_en_cours.md            ← vos abonnements (RSS, alertes, outils)
```

> Les documents de `veille-securite/` contiennent des exemples (en *italique* ou marqués « exemple ») à **remplacer par votre propre veille**.
